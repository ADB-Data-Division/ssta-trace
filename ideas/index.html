How the board works

  • Add a note with the box at the bottom, or double-click an empty spot on the board.
  • Move a note by dragging it. Everyone sees it move. Put similar ideas next to each other and add a heading above them.
  • Vote with the ▲ button. “Most votes” lists the ideas by votes.
  • Edit a note by double-clicking it, or use its ⋯ menu to change the colour, remove it or make it a project.
  • Look around: drag the background to move the board. Zoom with the buttons, with Ctrl + mouse wheel, or with two fingers.

Everyone with the link can add, move and remove notes: please treat it like a whiteboard in the room. Notes are stored in a Google Sheet of the workshop team. Do not write confidential or personal information on a note.
